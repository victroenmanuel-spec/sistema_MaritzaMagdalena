Estoy aprendiendo sobre Sistemas de Información Gerencial (SIG)

 3 cosas nuevas que descubrí sobre GitHub

1.	Control de versiones: GitHub guarda las versiones de tu código. Puedes volver a una versión anterior si quieres.
2.	Colaboración en equipo: Varias personas trabajan en el mismo proyecto al mismo tiempo. El trabajo de otros no se borra.
3.	Pull Requests: Puedes pedir cambiar el código. Todos pueden hablar sobre los cambios antes de añadirlos al proyecto.
   
Quiero aprender a:

- Usar sistemas para controlar versiones

- Hacer proyectos en grupo de forma simple

- Saber las mejores formas de hacer software

- Usar conocimientos de SIG en proyectos reales
